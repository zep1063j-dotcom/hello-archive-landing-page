# Hello_Archive 랜딩페이지

가족의 이야기를 질문과 답변으로 기록하는 서비스 **Hello_Archive**의 소개 및 사전 수요 검증용 랜딩페이지입니다.

## 파일 구조

```text
landing page/
├── index.html        # 페이지 전체 마크업 (13개 섹션)
├── css/
│   └── landing.css   # 디자인 토큰(CSS 변수), 스타일, 애니메이션
├── assets/
│   └── favicon.svg   # 브라우저 탭 아이콘 (로고 마크)
├── js/
│   ├── config.js     # 사이트 설정값 (사전 신청 폼 주소)
│   └── landing.js    # 모바일 메뉴, 스크롤 등장 효과, 타임라인 진행, 신청 버튼 연결
└── README.md
```

- 스택: HTML5 · CSS3 · Bootstrap 5.3.3(CDN) · Vanilla JS (추가 라이브러리 없음)
- 글꼴: 헤드라인 Gowun Batang(Google Fonts, 1종) + 본문은 기기 기본 고딕
- 빌드 도구, 서버, 데이터베이스 없음 — 정적 파일만으로 동작합니다.

## 페이지 구성 (위에서 아래 순서)

1. Header · 2. Hero (헤드라인 "일상의 질문이 인생의 챕터로") · 3. 부모님의 어린 시절(공감) · 3-1. 이런 분께 추천해요 ·
4. 사용 방법 3단계 · 5. 이야기 카드 미리보기 · 6. 기록 성장 타임라인 · 7. 부모님을 위한 설계 · 8. 가족 기록을 다루는 원칙 ·
**8-1. 앞으로 더해질 기능** (음성 답변, 목소리 기록, 앨범 PDF, 함께 기록하기는 "준비 중", 종이 책은 "검토 중"으로 표기) ·
9. FAQ · 10. 출시 소식 받기 · 11. Footer

## 실행 방법

1. `index.html`을 브라우저로 더블클릭해 열면 됩니다. (글꼴·Bootstrap을 인터넷에서 불러오므로 온라인 상태 필요)
2. 로컬 서버로 확인하고 싶다면 이 폴더에서:
   ```bash
   python3 -m http.server 8000
   ```
   후 브라우저에서 `http://localhost:8000` 접속.

## 디자인 시스템 (css/landing.css 상단 `:root`)

| 토큰 | 값 | 용도 |
|---|---|---|
| `--ha-black` | #1F1D1B | 브랜드 검정 — 버튼, 최종 CTA 배경 (**임시값**) |
| `--ha-red` | #B3261E | 브랜드 빨강 — 포인트, 강조 글자 (**임시값**) |
| `--ha-red-deep` | #8E1B16 | 빨강 hover, 책 표지 |
| `--ha-paper` | #F8F5EF | 메인 배경 |
| `--ha-paper-deep` | #EFE8DC | 교차 섹션 배경 |
| `--ha-ink` | #1F1D1B | 본문 텍스트 |
| `--ha-muted` | #5F5A55 | 보조 텍스트 |
| `--ha-clay` | #C58A72 | 따뜻한 보조색 — 장식 전용 |

브랜드 색상 코드가 확정되면 `--ha-black`, `--ha-red`, `--ha-red-deep` 세 줄만 바꾸면 페이지 전체에 반영됩니다.

## 인터랙션 (js/landing.js)

| 기능 | 동작 |
|---|---|
| 히어로 첫 등장 | 제목 → 책 → 질문 카드 → 답변 카드 순서로 한 번 등장 (CSS) |
| 스크롤 등장 | 질문 3개, 사용 단계 3개, 이야기 카드 2장, 타임라인 4단계, 휴대폰 화면이 순서대로 나타남 |
| 타임라인 진행 | 스크롤에 따라 1주 → 1년 단계가 차례로 채워지고, 현재 단계 제목이 빨간색으로 강조 |
| 모바일 메뉴 | 메뉴 항목을 누르면 메뉴가 닫힌 뒤 해당 섹션으로 이동, Esc 키로 닫기 |
| 헤더 | 스크롤하면 아래쪽 그림자, 보고 있는 섹션의 메뉴에 밑줄 |

- JavaScript가 꺼져 있거나 오류가 나도 모든 콘텐츠는 그대로 보입니다.
- 운영체제의 '동작 줄이기(Reduce motion)' 설정을 켜면 움직임 없이 바로 보여줍니다.

## 사전 신청 폼 연결하기

이 페이지는 자체 서버나 데이터베이스 없이, **외부 신청 폼(예: Google 폼)** 으로 연결합니다.

### 1. Google 폼 만들기
1. [forms.google.com](https://forms.google.com)에서 새 양식을 만듭니다. 제목 예: `Hello_Archive 출시 소식 받기`
2. 설정 → 응답 → **이메일 주소 수집**: `응답자 입력`으로 설정합니다. (이름, 전화번호, 부모님 정보는 받지 않습니다)
3. 질문을 하나 추가합니다: 유형 `체크박스`, 필수, 항목 `위 내용에 동의합니다` — 아래 고지 문구를 이 질문의 설명란에 넣습니다.
4. 오른쪽 위 **보내기 → 링크(🔗) → URL 단축** 을 눌러 주소(`https://forms.gle/...`)를 복사합니다.

### 2. 페이지에 연결하기
`js/config.js`를 열어 따옴표 안에 주소를 붙여 넣고 저장합니다.

```js
window.HELLO_ARCHIVE_CONFIG = {
  signupFormUrl: 'https://forms.gle/여기에-복사한-주소'
};
```

- 저장하면 마지막 영역의 "출시 소식 받기" 버튼이 신청 폼(새 창) 링크로 바뀝니다.
- 비워 두면 "준비 중" 상태로 돌아갑니다. `https://`로 시작하지 않는 주소는 무시됩니다.
- 이 파일은 공개 파일이므로 비밀번호나 API 키를 넣지 않습니다.
